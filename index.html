Tentang Coding Club

Coding Club SMKN 1 Subang merupakan wadah bagi siswa yang ingin mempelajari dunia pemrograman dan teknologi. Kegiatan ini bertujuan untuk meningkatkan kemampuan siswa dalam membuat program dan memahami dasar-dasar pengembangan perangkat lunak.

Dengan mengikuti Coding Club, siswa dapat belajar bersama, berbagi pengalaman, mengembangkan kreativitas, serta membuat berbagai proyek sederhana. Coding Club juga membantu siswa meningkatkan kemampuan kerja sama dan mempersiapkan diri menghadapi perkembangan teknologi.

Apa yang Dipelajari

  • CSS
  • JavaScript
  • Pemrograman Web
  • Git dan GitHub

Alur Mengikuti Coding Club

  2. Mengikuti pertemuan pertama
  3. Belajar dasar pemrograman
  4. Membuat proyek sederhana
  5. Presentasi hasil proyek
